# 工具实现

- 工具参数来自模型，按不可信输入处理。JSON Schema 与 execute 中的校验、默认值和实际行为应一致。
- 使用 src/agent/types.ts 的 Tool、ToolContext 和 ToolResult。普通执行不重复检查初始权限；额外授权通过 context.checkPermission 申请。
- 相对路径以 context.cwd 为准，拒绝空路径。文件操作失败时在错误信息中带上具体路径，方便模型修正参数。
- read_file 控制返回内容长度，截断时说明未展示的内容。edit 校验原文匹配情况，替换文本中的 $&、$1 等字符应原样写入。
- 文件写入成功后再报告成功；返回信息准确说明新建、覆盖或替换的结果。修改文件时保留无关内容。
- Bash 复用 process.ts 的 runCommand，传递超时、输出上限、sandbox 和 signal。超时和中断都要清理整个进程组，不能把父进程退出当作所有子进程结束。
- 命令失败或被中断时保留已有输出并注明结果。中断后不申请沙箱外重跑；需要重跑时说明前一次可能已经执行了部分操作，并通过权限回调取得结果。
- 工具不直接打印界面或修改会话历史。错误通过异常或 isError 交给主循环处理。
- 测试实际文件和子进程行为时使用独立临时目录，并清理文件及进程。检查返回值之外，也确认预期的文件和进程状态。
